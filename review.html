    Where these answers go, and what gets listed

    Your answers are saved in this browser only — nobody else can see them yet. Copy answers puts them on the clipboard so you can paste them into chat; Export downloads the same thing as a file. Either way they have to be sent over and published before a visitor to the map sees them. Import reads a file back, so answers survive a new phone or a cleared browser. Only places with an address are listed — without one there is nothing to stand in front of. Toilets that OpenStreetMap says you have to pay for are left out: this map is only for free ones. If one of them is really free, say so and it can go back on. Add a place drops a pin anywhere the map is missing one, and every card has a delete button for a place that should not be on the list at all.
